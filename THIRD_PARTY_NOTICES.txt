Nothing else third-party
------------------------
The playable tree was searched for further third-party material and none was
found:

  * Fonts     — no font files are shipped. The only font declaration is a
                system stack: ui-rounded, "SF Pro Rounded", system-ui,
                sans-serif. Nothing is downloaded.
  * Images    — no image files are shipped. Every mark in the game is an SVG
                path written inline in index.html or main.js, or is drawn on a
                canvas at run time. The tab icon is an inline data: URI.
  * Audio     — no audio files are shipped. All sound is synthesised in the
                browser with the Web Audio API.
  * Libraries — three.js is the only dependency. No build step, no bundler
                runtime, no polyfills, no analytics, and no fonts or scripts
                from any other origin.

One further attribution appears as a comment inside three.core.js, crediting an
algorithm to a book published by Morgan Kaufmann Publishers ((c) 2005 Elsevier
Inc.). It is an attribution for the method, not separately licensed code, and
it travels under the three.js MIT licence above.
